РОМАНТИЧЕСКАЯ ВЕБ-ОТКРЫТКА

Файлы:
- index.html — текст и структура открытки
- style.css — оформление, цвета, адаптация под телефон и анимации
- script.js — открытие письма и сердечки

КАК ПРОВЕРИТЬ НА КОМПЬЮТЕРЕ
1. Распакуйте ZIP в отдельную папку.
2. Откройте index.html двойным щелчком. Для проверки обычно достаточно браузера.
3. Интернет нужен для загрузки фонового изображения и шрифтов.

КАК ИЗМЕНИТЬ ТЕКСТ
Откройте index.html в VS Code.
- Замените «Моя любимая» на её имя.
- Измените абзацы внутри <article id="letterScreen"> на свои слова.
- Замените «Твой человек ❤️» на свою подпись.
Сохраните файл и обновите страницу.

КАК ОПУБЛИКОВАТЬ БЕСПЛАТНО ЧЕРЕЗ GITHUB PAGES
1. Войдите на https://github.com/ или создайте аккаунт.
2. Нажмите New repository и назовите его romantic-card.
3. Выберите Public и создайте репозиторий.
4. Нажмите Add file → Upload files.
5. Загрузите index.html, style.css и script.js (не сам ZIP).
6. Нажмите Commit changes.
7. Откройте Settings → Pages.
8. В разделе Build and deployment выберите Deploy from a branch.
9. Выберите Branch: main и folder: /(root), затем Save.
10. Подождите несколько минут. В разделе Pages появится ссылка вида:
    https://ВАШ-ЛОГИН.github.io/romantic-card/
11. Откройте ссылку и проверьте открытку на телефоне.

КАК ОТПРАВИТЬ ЧЕРЕЗ WHATSAPP
1. Скопируйте опубликованную ссылку.
2. Откройте чат с девушкой.
3. Например, напишите: «Я приготовил для тебя маленький сюрприз ❤️
   Открой эту ссылку, когда будет минутка: [вставьте ссылку]»
4. Отправьте сообщение. Она нажмёт ссылку и откроет открытку в браузере.

ВАЖНО
- В WhatsApp лучше отправлять именно ссылку, а не HTML-файл: телефон может показать код или не открыть файл как сайт.
- Не отправляйте ссылку до публикации: локальный адрес вроде file:///C:/... работает только на вашем устройстве.
- Фоновая фотография и шрифты загружаются из интернета, поэтому внешний вид может немного отличаться при отсутствии сети.
